# drzakerullah.com

Private-practice website for Mr Md Zaker Ullah FRCS, consultant oncoplastic breast & general
surgeon in London & Essex. Static, dependency-free, generated by a small Python build.

## Quick start

```bash
python3 _build/validate.py   # lint blog posts against content/BLOG-RULES.md
python3 _build/build.py      # regenerate every page, sitemap.xml, feed.xml, llms.txt
python3 -m http.server 8765  # preview at http://localhost:8765
```

Push to `main` and GitHub Actions validates, builds and deploys to GitHub Pages. It also runs
**daily at 06:00 UTC**, so blog posts with a future `date:` publish themselves on that day.

## Structure

| Source | Produces |
|---|---|
| `_build/content.py` | Facts: treatments, clinics, insurers, verbatim iWantGreatCare reviews, podcast |
| `_build/build.py` | Home, About, 8 treatment pages, Second opinion, 3 clinic pages, Reviews, Podcast, Insights, Booking, 404 |
| `_build/layout.py` | `<head>`, header (mega-menus), footer, CTA, mobile booking bar |
| `content/blog/*.md` | Blog posts → `/news/<slug>/` (+ FAQ schema from the FAQ section) |
| `content/BLOG-RULES.md` | Editorial, medical, compliance and SEO rules for posts |
| `content/content-plan.md` | Researched backlog of 40+ topics |
| `CLAUDE.md` | How Claude should write and schedule posts |
| `assets/` | CSS design system, JS (menu, video facade, enquiry form), fonts, images |

## SEO built in

- Physician, MedicalClinic (per real clinic), MedicalWebPage (reviewedBy/lastReviewed),
  MedicalProcedure, BlogPosting, FAQPage, BreadcrumbList, PodcastEpisode and VideoObject JSON-LD.
- No AggregateRating markup: Google ignores self-serving review stars and it risks a manual action.
  Reviews are shown visibly and link to iWantGreatCare.
- One page per **real** clinic only. No neighbourhood "doorway" pages.
- Keyword-led titles and descriptions, canonical URLs, sitemap, RSS, `llms.txt` for AI search.
- WebP images, self-hosted fonts, YouTube loads only on click. Fast and Core Web Vitals-friendly.

## Going live on www.drzakerullah.com

1. GitHub → repo **Settings → Pages**: Source = GitHub Actions (already set). Add custom domain
   `www.drzakerullah.com` and tick *Enforce HTTPS*.
2. At the domain registrar (currently Squarespace Domains): CNAME `www` → `umsie121.github.io`,
   and A records for the apex → 185.199.108.153 / .109.153 / .110.153 / .111.153.
3. Google Search Console: verify the domain, submit `https://www.drzakerullah.com/sitemap.xml`.
